# Langkah 1: Pilih API

## Apa langkah ini

Kuliah bermula dengan memilih API awam yang memulangkan data watak sebagai JSON.

## Apa yang dilakukan

API kuliah sendiri sudah ditamatkan dan satu calon lagi digantung, jadi saya menyemak bahawa API masih menjawab sebelum menulis kod. Pilihan saya ialah Potter API oleh fedeperin: tiada kunci, JSON biasa dan asrama bagi setiap watak.

## Apa yang dipelajari

API percuma boleh hilang. Dengan menulis pilihan sebagai keputusan seni bina (ADR-0001) dan menyembunyikan API di sebalik port, perubahan kemudian hanya menyentuh satu kelas.
