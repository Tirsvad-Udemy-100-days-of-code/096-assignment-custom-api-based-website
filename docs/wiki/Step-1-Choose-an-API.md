# Step 1: Choose an API

## What this step is

The lecture starts by picking a public API that returns character data as JSON.

## What was done

The lecture's own API is retired and a second candidate was suspended, so checking that an API still answers came before any code. The choice is the Potter API by fedeperin: no key, plain JSON, and a house on each character.

## What was gained

A free API can disappear. Writing the choice down as an architecture decision (ADR-0001) and hiding the API behind a port means a later change touches one class.
