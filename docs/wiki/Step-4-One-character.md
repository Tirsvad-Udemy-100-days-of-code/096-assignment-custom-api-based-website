# Step 4: One character

## What this step is

The route `/character/<id>` shows the details of one character.

## What was done

The page shows name, nickname, house, actor, children and birthdate. Missing values are shown as a dash instead of breaking the page.

## What was gained

Real data is incomplete. Designing for missing fields from the start avoids errors that only appear with some characters.
