# Trin 1: Vælg et API

## Hvad trinnet er

Lektionen starter med at vælge et offentligt API, der returnerer figurdata som JSON.

## Hvad jeg gjorde

Lektionens eget API er lukket, og en anden kandidat var suspenderet, så jeg tjekkede først, at et API stadig svarer, før jeg skrev kode. Valget blev Potter API fra fedeperin: ingen nøgle, almindelig JSON og et hus på hver figur.

## Hvad jeg lærte

Et gratis API kan forsvinde. Når valget er skrevet ned som en arkitekturbeslutning (ADR-0001), og API'et ligger bag en port, rammer en senere ændring kun én klasse.
