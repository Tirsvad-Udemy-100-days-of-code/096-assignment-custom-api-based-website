# Harry Potter website, Day 96

A small Flask website that shows Harry Potter characters from a public REST API. It is the Day 96 assignment of *100 Days of Code*. This wiki walks through the five lecture steps. Each page says what the step is, what it taught and shows a screenshot.

| Step | Page |
| --- | --- |
| 1 | [Choose an API](Step-1-Choose-an-API) |
| 2 | [Show the data](Step-2-Show-the-data) |
| 3 | [Filter by house](Step-3-Filter-by-house) |
| 4 | [One character](Step-4-One-character) |
| 5 | [When the API fails](Step-5-When-the-API-fails) |
| - | [Reflection](Reflection) |

The code is in layers: `domain`, `application`, `infrastructure` and `presentation`. Flask is the only runtime dependency. See the repository README for setup and the commands to run the site and the tests.
